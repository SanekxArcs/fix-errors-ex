AI Configuration

Start LM Studio → open the Local Server tab → click Start Server. Enable CORS in LM Studio settings so the extension can connect.

Rules: Select text on any page, right click, and choose "Fix typos and grammar".

Translation: Append "en to pl" or "ua to en" at the end of selection to translate.

Default shortcuts: Alt+Shift+F (fix grammar), Alt+Shift+G (fix selected), Alt+Shift+A (AI prompt).

To change them, go to chrome://extensions/shortcuts in your browser, find Fix Errors AI, and click the pencil icon next to the shortcut.
